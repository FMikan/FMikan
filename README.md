I'm a third-year Computer Science student at the Technical Faculty, University of Rijeka, currently working at **TRON**, where I work with software solutions, Geographic Information Systems (GIS), and geospatial data processing.

My work and interests span multiple areas of technology, including web application development, backend engineering, database systems, and geospatial technologies. I work with GIS tools such as **QGIS and QField**, focusing on spatial data processing, geographic data management, and field data collection workflows.

Beyond GIS, I enjoy exploring Linux environments, automation, modern software architectures, and practical applications of LLMs. I'm particularly interested in building reliable systems that connect software engineering with real-world applications.
